# Tic-Tac-Toe Game (C++)

## Overview
This project is a console-based Tic-Tac-Toe game developed in C++. It supports both 3x3 and 4x4 game modes and demonstrates object-oriented programming, input validation, game logic implementation, and file handling concepts.

In addition to the original implementation, an enhanced version of the project has been developed with expanded functionality, including user authentication, score tracking, replay management, and file-based account storage.

---

## Features

### Original Version
- 3x3 Tic-Tac-Toe mode
- 4x4 Tic-Tac-Toe mode
- Player account input
- Continue saved game option
- Input validation
- Win and draw detection
- Console-based game board display

### Enhanced Version
- User registration and login authentication
- File-based account storage
- Score tracking across multiple rounds
- Alternating starting player
- Replay functionality
- Improved input validation
- Match result dashboard
- Final match result summary
- Support for both 3x3 and 4x4 game modes
